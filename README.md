# New Look Tailor – Inventory

An offline-first, cross-platform inventory management app built for
New Look Tailor, a family tailoring and tailoring-materials shop.

Track fabrics, threads, buttons, zips, and accessories; record stock
in/out; get low-stock alerts; and keep data safe with automatic
backup and sync to the owner's personal Google Drive.

**Platforms:** Android · iOS · Windows · macOS · Linux · Web
**Stack:** Flutter · Dart · Riverpod · Drift (SQLite) · Google Sign-In · Google Drive API
